# 공통 화면 최적화 측정

같은 Windows PC에서 Python 3.14.7, NumPy 2.5.3을 사용하였습니다. 각 항목은 3회 중앙값이며 계산 정확도 개선이나 다른 PC의 속도를 보장하는 수치가 아닙니다.

| 항목 | BEFORE | AFTER |
|---|---:|---:|
| 새 Python 프로세스에서 Fourier 모듈 가져오기·객체 생성 | 898.2 ms | 409.1 ms |
| Fourier 기본 결과 표시 | 206.1 ms | 132.6 ms |
| 열전도 기본 결과 표시 | 193.7 ms | 73.0 ms |
| 원형 막 기본 결과 표시 | 170.4 ms | 141.9 ms |
| 열전도 결과의 추가 NumPy 표 저장량 | 1,216,360 bytes | 1,936 bytes |
| 원형 막 결과의 추가 NumPy 표 저장량 | 197,640 bytes | 1,296 bytes |

결과 표시 시간은 미리 계산한 결과를 화면에 전달하고 Qt 이벤트를 처리하는 시간입니다. 수학 계산·애니메이션 재생은 제외합니다. 숨겨진 그래프의 캔버스 생성과 그리기는 해당 탭을 처음 열 때 발생합니다. 모든 Figure의 구성 자체를 지연하는 최적화는 아닙니다.

표 저장량은 추가 NumPy 표 배열의 `nbytes` 합계입니다. 원본 계산 배열, Python 객체, 그래프, 프로세스 전체 메모리는 포함하지 않습니다. 행 뷰는 원본을 참조하므로 원본 메모리는 계속 필요합니다. CSV는 전체 문자열을 만들지 않고 ZIP에 순차 기록합니다.

## 재현

프로젝트 루트에서 다음 명령을 실행하십시오. 변경 전후에는 같은 환경·기본 입력을 사용하고 다른 계산을 동시에 실행하지 마십시오.

```powershell
.venv\Scripts\python.exe scripts/benchmark_workbench.py current
```

결과는 `build/workbench-current.json`에 기록됩니다. 처음 측정한 이전 버전 결과와 변경 후 결과도 이번 작업의 `build/workbench-before.json`, `build/workbench-after.json`에 보관하였습니다. 해당 생성 파일은 Git으로 추적하지 않습니다.

## 파일 정리

구형 GUI·중복 배포·완료된 배포 검사 복사본을 정리하여 총 4,796,732,719 bytes(약 4.47 GiB)를 확보하였습니다. 이는 코드 최적화에 따른 실행 메모리 절감이 아니라 로컬 파일 정리 결과입니다. 현재 가상환경과 최신 기존 배포본 1.5는 유지하였습니다.
